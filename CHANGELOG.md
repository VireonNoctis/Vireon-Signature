# Changelog

## 2.0.0 — React / Three.js redesign

### Added
- Ten signature finishes plus a custom colour system.
- Animated Three.js coastal atmosphere.
- Monochrome glass editor and animated signature preview.
- Progressive insertion guide for major email clients.
- Portrait, brand-mark and minimal signature compositions.

### Changed
- Replaced Vue and TypeScript with React and JavaScript.
- Replaced the custom canvas background with a Three.js scene.
- Reworked layout, preview and style selection around the supplied signature video.

### Preserved
- Framework-independent email-safe HTML renderer.
- Local-only drafts and HTML/text export.
- Existing repository governance and useful regression coverage.
